# UC01: Customer FAQ Agent

**Topology companion:** [L01 Hello LLM](../../deployment/01-hello-llm/)
**Prerequisites:** None

## Scenario

A customer-facing FAQ agent that answers product questions using a knowledge
base. The simplest useful CaseHub deployment — one agent, one purpose, no
escalation.

## What the topology level teaches

L01 shows **how** to deploy four services via claudony with dependency ordering.
This use case shows **why** — a real FAQ agent serving real customers.
