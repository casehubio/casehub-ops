# UC02: Audited Support

**Topology companion:** [L02 Accountability](../../deployment/02-accountability/)
**Prerequisites:** UC01

## Scenario

A support agent where every response is logged to the audit trail. Compliance
requires a tamper-evident record of what the agent said and when. The ledger
provides cryptographic guarantees that logs haven't been altered.

## What the topology level teaches

L02 shows **how** ledger and work services add audit trail and task tracking.
This use case shows **why** — regulated industries need provable response history.
