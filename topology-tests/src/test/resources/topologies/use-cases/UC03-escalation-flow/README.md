# UC03: Escalation Flow

**Topology companion:** [L03 Case Management](../../deployment/03-case-management/)
**Prerequisites:** UC02

## Scenario

A chat conversation escalates to a formal case. The agent can't resolve the
issue — qhorus creates a case, assigns it to a human specialist, and tracks
resolution. The customer sees continuity; the agent sees a handoff.

## What the topology level teaches

L03 shows **how** qhorus adds case-driven operations to the platform.
This use case shows **why** — not everything can be resolved by an agent.
