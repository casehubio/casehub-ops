# UC06: Maintenance Window

**Topology companion:** [L06 Lifecycle](../../deployment/06-lifecycle/)
**Prerequisites:** UC05

## Scenario

Scheduled maintenance — suspend the overnight shift agents, apply updates,
resume them for the morning shift. Business continuity requires that some
agents stay live while others are cycled. Lifecycle management orchestrates
the rotation.

## What the topology level teaches

L06 shows **how** suspend and resume operations work with status transitions.
This use case shows **why** — maintenance windows are a business reality.
